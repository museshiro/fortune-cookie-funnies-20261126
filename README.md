## The fortune

> You will finally understand the legacy code the day before it is deleted.

One line, 73 characters. The cruelest timing in engineering: mastery arrives
the day before the thing you mastered is thrown away.

## How it works

`main.ts` writes that single line to `/output/entry.txt` and nothing else.
No relative writes, so it runs cleanly in a read-only working directory.

## Run

```sh
npx tsx main.ts   # or: node --experimental-strip-types main.ts
cat /output/entry.txt
```
